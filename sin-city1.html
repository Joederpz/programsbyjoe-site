Frank Miller's Sin City is known for it's noir style with vibrant hints of red to add contrast to the scene. I have always loved the effect this can have on a scene. So I decided to write a shader that would make that same effect in my games and now I want to share that shader with you! I will assume that you have some previous knowledge of shaders and how to write them, but if this is your first time writing a shader click this link to get a little background information on shaders, how to write them, and some basic shaders to get you started.

Step 1 : Declare our Properties

To make this shader, 2 things are needed,  a variable for our main texture and a float range to control the intensity of the shader. I called my variables _MainTex and _bwBlend. We need these variables for a couple reasons, the _MainTex variable will be used to hold the texture that will be modified. the _bwBlend variable is a float that will change the intensity of our noir effect. A value of 0 will turn off the image effect while a value of 1 will be fully black and white.

Step 4 : Frag function


This is where all the magic happens! What the code will do is take the rgb values from the _MainTex and store them in a float4. Next step would be to make the grayscale value for each channel. To do this we will make a float called lum and pass in these magic numbers to grayscale any color. After we have our grayscale value we can assign it to the green and blue values of of a float3, leaving the red as the original float4's red channel. Then create a new float4 and store your original float4 in it. After that do a simple lerp between your first float4's.rgb and your float3 that holds the red channel and the two grayscale channels. Finally return your new float4 and you will have a stunning new image effect!

Step 5 : Create C# variables


The 2 variables needed for the C# portion are used to interface with the properties of the shader script. We must write a C# script to apply to our camera because shader files can not be directly applied to a camera. Therefore we need a variable to control the intensity and a variable to hold the material is needed.

Step 6 : On Awake


This is an easy step, find your image effect and assign it to your material, to do this you will need to call the function Shader.Find() Then pass in the path and the name of your shader. Usually I like to add a short debug.log after this line that will let the dev know if the material has been found or not, this is not necessary it just makes troubleshooting easier.

Step 7 : Postprocess the image


This is where we are actually sending our shader the information from our C# script. To do this we will use the OnRenderImage() function. Pass in your source RenderTexture and your destination RenderTexture. Next we do a simple if statement to check if the intensity is 0, if it is then we don't really have to do anything because our intensity is off.  Otherwise we will assign our material's _bwBlend the C#'s intensity variable. Then call the Blit() to render it to our screen.
