Volumetrica

Volumetric Player and Browser (C#)

UVP is a volumetric video playing solution. It has the ability to play full videos in 3D.  The application was designed to pull all data from a cloud server and upload to multiple applications including a steam game, mobile application, vr application, ar application, and desktop application. UVP was designed to give users the ability to walk around and fully experience a scene to the point where they can see every angle of the subject using volumetric capture and photogrammetry models. Users can scale and manipulate the models in real time using touch screen controls. 

Role : Lead Programmer
  • Content Creation Tool
  • Content Streaming and Downloading Functionality
  • Prototyping New Concepts Using the 4DS System
