Sin City//

Shader and image effect tutorial.

← All tutorials

Frank Miller’s Sin City is known for its noir style with vibrant hints of red to add contrast to the scene. I have always loved the effect this can have on a scene, so I wrote a shader that makes that same effect in my games, and now I want to share it with you! I assume you have some previous knowledge of shaders and how to write them. If this is your first time writing a shader, click this link for a little background, how to write them, and some basic shaders to get you started.

Step 1

Declare our Properties//

To make this shader, two things are needed: a variable for our main texture and a float range to control the intensity of the shader. I called my variables _MainTex and _bwBlend. The _MainTex variable holds the texture that will be modified. The _bwBlend variable is a float that changes the intensity of our noir effect. A value of 0 turns the image effect off, while a value of 1 is fully black and white.

Step 4

Frag function//

This is where all the magic happens! The code takes the rgb values from _MainTex and stores them in a float4. Next, make the grayscale value for each channel: create a float called lum and pass in the magic numbers that grayscale any color. Assign that grayscale value to the green and blue values of a float3, leaving the red as the original float4’s red channel. Then create a new float4 and store your original float4 in it. After that, do a simple lerp between your first float4’s rgb and the float3 holding the red channel and the two grayscale channels. Finally, return your new float4 and you will have a stunning new image effect!
